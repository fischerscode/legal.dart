# Third-party detection data

The SPDX license and exception identifier sets in
`lib/src/licenses/spdx_ids.dart` are extracted from the official
[SPDX License List data, version 3.29.0](https://github.com/spdx/license-list-data/tree/v3.29.0)
(`json/licenses.json` and `json/exceptions.json`). The upstream source is
[SPDX License List XML](https://github.com/spdx/license-list-XML).
No SPDX implementation code is copied into this package.

Full reference texts for MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0, and ISC in
`lib/src/licenses/reference_texts.dart` are copied from that release's `text/`
directory as reference data for reviewing cosmetic matching differences and for
tests. Identification itself uses the tightly constrained pana dependency. Their complete original texts are retained in
that source file and never substituted for dependency-supplied documents.
This attribution does not relicense upstream license texts as legal's BSD-3-Clause
implementation license.

Resolved runtime package inventories are generated by `legal generate`.
This document covers vendored reference data rather than resolved dependencies.

## Embedded native runtime license texts

`lib/src/licenses/runtime_data.g.dart` embeds original upstream license texts
from the exact revisions recorded in `tool/runtime_licenses/3.13.4/manifest.json`.
They cover BoringSSL, ICU, zlib, double-conversion, libc++, libc++abi and V8 RegExp.
The complete texts, including their copyright and attribution notices, are
retained without rewriting; this package's implementation license does not
replace their original terms. No native implementation code is vendored here.
The provenance, hashes and partial audit scope are described in
`tool/runtime_licenses/README.md`. Runtime catalog data is embedded even in a
compiled legal executable; collection never downloads it.
